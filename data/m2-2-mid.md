## 24. 공민왕의 개혁

### 14세기 중반 원의 세력을 등에 업고 횡포를 부리다가 공민왕에게 제거된 기황후의 오빠는?
- [x] 기철
- [ ] 이자춘 — 이성계의 아버지, 쌍성총관부 회복을 도움
- [ ] 신돈 — 공민왕이 등용해 전민변정도감을 맡긴 인물
- [ ] 최영 — 왜구를 물리치고 요동 정벌을 주장한 장수
> 기철 등은 원의 세력을 등에 업고 왕권을 위협했고, 공민왕은 기철을 제거하고 개혁을 시작했다. (p.88)

### 공민왕이 신돈을 등용해 설치하고, 권문세족이 빼앗은 토지와 농민을 원래대로 되돌린 기구는?
- [x] 전민변정도감
- [ ] 교정도감 — 최씨 무신정권의 최고 권력 기구 (1학기)
- [ ] 정동행성 — 원이 일본 원정을 위해 고려에 설치한 기구
- [ ] 집현전 — 조선 세종이 세운 학문 연구 기관
> 전민변정도감은 권문세족이 불법으로 빼앗은 토지를 돌려주고 억울하게 노비가 된 사람을 양민으로 되돌렸다. (p.88)

### 공민왕이 공격하여 원에게 빼앗겼던 영토를 되찾은 곳은?
- [x] 쌍성총관부
- [ ] 동녕부 — 원이 서경(평양)에 설치한 기관 (1학기)
- [ ] 4군 6진 — 조선 세종 때 여진을 몰아내고 개척한 지역
- [ ] 위화도 — 이성계가 요동 공격을 멈추고 군사를 돌린 곳
> 공민왕은 쌍성총관부를 공격해 원에 빼앗겼던 동북 지역의 영토를 되찾았다(1356). (p.88)

### 공민왕의 개혁 정치로 알맞지 않은 것은?
- [x] 몽골의 침입을 피해 강화도로 수도를 옮겼다.
- [ ] 정동행성의 일부 기능을 폐지했다. — 공민왕의 반원 개혁 (맞는 내용)
- [ ] 격이 낮아졌던 왕실과 관제의 호칭을 복구했다. — 공민왕의 반원 개혁 (맞는 내용)
- [ ] 원을 몰아낸 명과 조공·책봉 관계를 맺었다. — 새 국제 질서에 대응 (맞는 내용)
> 강화도 천도는 몽골 침입 때 최우 정권이 한 일이다(1학기). 공민왕은 반원 개혁과 함께 새로 일어난 명과 관계를 맺었다. (p.88)

### 원의 관리였지만 고려에 귀순해 쌍성총관부 회복을 도운, 이성계의 아버지는?
- [x] 이자춘
- [ ] 이지란 — 여진 부족장, 이성계의 의형제
- [ ] 기철 — 원을 등에 업고 횡포를 부린 기황후의 오빠
- [ ] 정몽주 — 고려 왕조 유지를 주장한 신진 사대부
> 이자춘과 이지란은 고려 동북 지역의 독자적인 세력으로, 공민왕이 쌍성총관부를 되찾는 데 크게 기여했다. (p.88)

### 공민왕 때 원에서 반란을 일으킨 뒤 고려까지 쳐들어와 한때 개경을 함락한 세력은?
- [x] 홍건적
- [ ] 왜구 — 해안을 약탈한 대규모 해적 집단
- [ ] 거란 — 고려 초에 세 차례 침입한 나라 (1학기)
- [ ] 여진 — 조선 세종 때 4군 6진을 개척하며 몰아낸 민족
> 홍건적이 개경을 함락하자 공민왕은 안동(복주)까지 피난했다. (p.89)

### 홍건적과 왜구를 물리치며 백성들의 신망을 얻어 새로운 정치 세력으로 등장한 이성계 등의 세력은?
- [x] 신흥 무인 세력
- [ ] 신진 사대부 — 성리학을 공부하고 과거로 진출한 개혁 세력
- [ ] 권문세족 — 원 간섭기의 지배층, 공민왕 개혁에 반발
- [ ] 문벌 — 고려 전기에 고위 관직을 독차지한 가문 (1학기)
> 이성계 등 신흥 무인 세력은 홍건적과 왜구를 물리치는 데 큰 공을 세웠다. (p.89)

### 성리학을 받아들이고 과거로 관직에 나아가 공민왕의 개혁을 뒷받침한 새로운 정치 세력은?
- [x] 신진 사대부
- [ ] 신흥 무인 세력 — 홍건적·왜구를 물리친 이성계 등
- [ ] 권문세족 — 원 간섭기의 지배층, 개혁에 반발
- [ ] 훈구 — 조선 세조의 즉위를 도운 세력
> 신진 사대부는 불법적인 농장 확대와 불교계의 타락을 비판하며 사회 개혁을 주장했다. (p.89)

### 명이 옛 쌍성총관부 지역을 요구하자 "이 기회에 요동을 되찾아 오자"고 주장한 인물은?
- [x] 최영
- [ ] 이성계 — 큰 나라 명과 맞서면 안 된다며 요동 공격에 반대
- [ ] 정몽주 — 고려 왕조를 유지하며 개혁하자고 주장
- [ ] 정도전 — 새 왕조를 세우자고 주장
> 최영은 요동 정벌을 주장했고, 이성계는 반대했다. (p.89)

### 신진 사대부 중 "고려에 충성하면서도 개혁할 수 있으니 왕조를 바꿀 필요가 없다"고 주장한 인물은?
- [x] 정몽주
- [ ] 정도전 — "고려는 이미 썩었다"며 새 왕조 건설을 주장
- [ ] 최영 — 요동 정벌을 주장한 장수
- [ ] 이성계 — 신흥 무인 세력, 훗날 조선의 태조
> 정몽주와 정도전은 같은 스승 밑에서 성리학을 공부했지만 고려의 운명을 두고 의견이 갈렸다. (p.89)

### 1380년 진포에서 왜구를 물리친 인물은?
- [x] 최무선
- [ ] 최영 — 홍산에서 왜구를 물리침(1376)
- [ ] 이성계 — 황산에서 왜구를 물리침(1380)
- [ ] 정세운 — 홍건적을 물리침(1362)
> 홍건적과 왜구의 침입 지도에 나오는 인물들이다. (p.89)

## 27. 조선의 건국

### 요동을 공격하라는 명령을 받은 이성계가 군사를 돌려 개경으로 돌아와 권력을 장악한 사건은?
- [x] 위화도 회군
- [ ] 인조반정 — 서인이 광해군을 몰아내고 인조를 세운 사건(1623)
- [ ] 무신정변 — 무신들이 문신을 죽이고 권력을 잡은 사건(1170, 1학기)
- [ ] 정묘호란 — 후금이 조선을 침입한 전쟁(1627)
> 위화도 회군 이후 신진 사대부와 신흥 무인 세력이 권력을 잡았다. (p.104)

### 신진 사대부가 시행한 토지 제도로, 관리 등급에 따라 토지에서 세금을 걷을 권리를 나누어 준 것은?
- [x] 과전법
- [ ] 전시과 — 고려의 토지 제도 (1학기)
- [ ] 대동법 — 특산물 대신 쌀·옷감으로 내게 한 세금 제도
- [ ] 균역법 — 영조가 군포를 2필에서 1필로 줄인 제도
> 과전법으로 권문세족의 경제력을 약화하고, 세금을 수확량의 10분의 1로 정해 백성의 부담을 덜었다. (p.104)

### 조선의 건국에 대한 설명으로 알맞은 것은?
- [x] 1392년 이성계가 왕이 되어 나라 이름을 조선으로 바꾸고 한양으로 수도를 옮겼다.
- [ ] 918년 왕건이 송악에서 나라를 세웠다. — 고려의 건국 (1학기)
- [ ] 1392년 정몽주가 이성계를 왕으로 추대했다. — 정몽주는 고려 유지를 주장하다 제거됨
- [ ] 1446년 세종이 즉위하며 나라를 세웠다. — 1446년은 훈민정음을 반포한 해
> 정도전 등은 고려 왕조 유지를 주장한 정몽주를 제거하고 이성계(태조)를 왕으로 세웠다. (p.104)

### 한성(한양)에서 경복궁 동쪽에 두어 왕의 조상들에게 제사를 지낸 곳은?
- [x] 종묘
- [ ] 사직 — 경복궁 서쪽, 토지신과 곡식신에게 제사
- [ ] 성균관 — 유학 최고 교육 기관
- [ ] 종각 — 도성 중앙에 세운 종루
> 경복궁을 중심으로 동쪽에는 종묘, 서쪽에는 사직을 두었다. (p.104~105)

### 재상 중심의 정치와 요동 정벌을 주장하다 이방원에게 제거된 인물은?
- [x] 정도전
- [ ] 정몽주 — 고려 왕조 유지를 주장하다 조선 건국 전에 제거됨
- [ ] 최영 — 요동 정벌을 주장한 고려 말 장수
- [ ] 조광조 — 중종 때 개혁을 추진한 사림
> 정도전은 재상이 임금의 좋은 점은 따르고 나쁜 점은 바로잡아야 한다고 보았다. 이방원은 왕 중심 정치를 주장했다. (p.105)

### 태종(이방원)의 정책으로 알맞지 않은 것은?
- [x] 집현전을 설치해 학자를 길렀다.
- [ ] 사병을 없애 군사권을 장악했다. — 태종의 정책 (맞는 내용)
- [ ] 인구 조사를 실시했다. — 태종의 정책 (맞는 내용)
- [ ] 호패법을 시행했다. — 태종의 정책 (맞는 내용)
> 집현전은 세종이 설치했다. 태종은 사병 혁파, 인구 조사, 호패법으로 왕권과 국가 재정을 안정시켰다. (p.105~106)

### 세종이 유교적 소양을 갖춘 학자들을 키우기 위해 설치한 학문 연구 기관은?
- [x] 집현전
- [ ] 홍문관 — 성종이 집현전을 계승해 설치
- [ ] 규장각 — 정조가 세운 학문·정책 연구 기관
- [ ] 의금부 — 왕의 특별 사법 기관
> 집현전(세종) → 홍문관(성종이 계승) → 규장각(정조)의 흐름을 기억하자. (p.106)

### 왕이 신하들과 함께 유교 경전을 공부하고 나라의 중요한 일을 논의하던 자리는?
- [x] 경연
- [ ] 예송 — 상복 입는 기간을 둘러싼 붕당 간 논쟁
- [ ] 환국 — 숙종 때 집권 붕당이 한꺼번에 바뀐 일
- [ ] 향약 — 사림이 만든 향촌 자치 규약
> 세종은 경연을 1,898회나 열 만큼 신하들과의 대화를 중요하게 여겼다. (p.106)

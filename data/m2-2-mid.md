## 24. 공민왕의 개혁

### 14세기 중반 원의 세력을 등에 업고 횡포를 부리다가 공민왕에게 제거된 기황후의 오빠는?
- [x] 기철
- [ ] 이자춘 — 이성계의 아버지, 쌍성총관부 회복을 도움
- [ ] 신돈 — 공민왕이 등용해 전민변정도감을 맡긴 인물
- [ ] 최영 — 왜구를 물리치고 요동 정벌을 주장한 장수
> 기철 등은 원의 세력을 등에 업고 왕권을 위협했고, 공민왕은 기철을 제거하고 개혁을 시작했다. (p.88)

### 공민왕이 신돈을 등용해 설치하고, 권문세족이 빼앗은 토지와 농민을 원래대로 되돌린 기구는?
- [x] 전민변정도감
- [ ] 교정도감 — 최씨 무신정권의 최고 권력 기구 (1학기)
- [ ] 정동행성 — 원이 일본 원정을 위해 고려에 설치한 기구
- [ ] 집현전 — 조선 세종이 세운 학문 연구 기관
> 전민변정도감은 권문세족이 불법으로 빼앗은 토지를 돌려주고 억울하게 노비가 된 사람을 양민으로 되돌렸다. (p.88)

### 공민왕이 공격하여 원에게 빼앗겼던 영토를 되찾은 곳은?
- [x] 쌍성총관부
- [ ] 동녕부 — 원이 서경(평양)에 설치한 기관 (1학기)
- [ ] 4군 6진 — 조선 세종 때 여진을 몰아내고 개척한 지역
- [ ] 위화도 — 이성계가 요동 공격을 멈추고 군사를 돌린 곳
> 공민왕은 쌍성총관부를 공격해 원에 빼앗겼던 동북 지역의 영토를 되찾았다(1356). (p.88)

### 공민왕의 개혁 정치로 알맞지 않은 것은?
- [x] 몽골의 침입을 피해 강화도로 수도를 옮겼다.
- [ ] 정동행성의 일부 기능을 폐지했다. — 공민왕의 반원 개혁 (맞는 내용)
- [ ] 격이 낮아졌던 왕실과 관제의 호칭을 복구했다. — 공민왕의 반원 개혁 (맞는 내용)
- [ ] 원을 몰아낸 명과 조공·책봉 관계를 맺었다. — 새 국제 질서에 대응 (맞는 내용)
> 강화도 천도는 몽골 침입 때 최우 정권이 한 일이다(1학기). 공민왕은 반원 개혁과 함께 새로 일어난 명과 관계를 맺었다. (p.88)

### 원의 관리였지만 고려에 귀순해 쌍성총관부 회복을 도운, 이성계의 아버지는?
- [x] 이자춘
- [ ] 이지란 — 여진 부족장, 이성계의 의형제
- [ ] 기철 — 원을 등에 업고 횡포를 부린 기황후의 오빠
- [ ] 정몽주 — 고려 왕조 유지를 주장한 신진 사대부
> 이자춘과 이지란은 고려 동북 지역의 독자적인 세력으로, 공민왕이 쌍성총관부를 되찾는 데 크게 기여했다. (p.88)

### 공민왕 때 원에서 반란을 일으킨 뒤 고려까지 쳐들어와 한때 개경을 함락한 세력은?
- [x] 홍건적
- [ ] 왜구 — 해안을 약탈한 대규모 해적 집단
- [ ] 거란 — 고려 초에 세 차례 침입한 나라 (1학기)
- [ ] 여진 — 조선 세종 때 4군 6진을 개척하며 몰아낸 민족
> 홍건적이 개경을 함락하자 공민왕은 안동(복주)까지 피난했다. (p.89)

### 홍건적과 왜구를 물리치며 백성들의 신망을 얻어 새로운 정치 세력으로 등장한 이성계 등의 세력은?
- [x] 신흥 무인 세력
- [ ] 신진 사대부 — 성리학을 공부하고 과거로 진출한 개혁 세력
- [ ] 권문세족 — 원 간섭기의 지배층, 공민왕 개혁에 반발
- [ ] 문벌 — 고려 전기에 고위 관직을 독차지한 가문 (1학기)
> 이성계 등 신흥 무인 세력은 홍건적과 왜구를 물리치는 데 큰 공을 세웠다. (p.89)

### 성리학을 받아들이고 과거로 관직에 나아가 공민왕의 개혁을 뒷받침한 새로운 정치 세력은?
- [x] 신진 사대부
- [ ] 신흥 무인 세력 — 홍건적·왜구를 물리친 이성계 등
- [ ] 권문세족 — 원 간섭기의 지배층, 개혁에 반발
- [ ] 훈구 — 조선 세조의 즉위를 도운 세력
> 신진 사대부는 불법적인 농장 확대와 불교계의 타락을 비판하며 사회 개혁을 주장했다. (p.89)

### 명이 옛 쌍성총관부 지역을 요구하자 "이 기회에 요동을 되찾아 오자"고 주장한 인물은?
- [x] 최영
- [ ] 이성계 — 큰 나라 명과 맞서면 안 된다며 요동 공격에 반대
- [ ] 정몽주 — 고려 왕조를 유지하며 개혁하자고 주장
- [ ] 정도전 — 새 왕조를 세우자고 주장
> 최영은 요동 정벌을 주장했고, 이성계는 반대했다. (p.89)

### 신진 사대부 중 "고려에 충성하면서도 개혁할 수 있으니 왕조를 바꿀 필요가 없다"고 주장한 인물은?
- [x] 정몽주
- [ ] 정도전 — "고려는 이미 썩었다"며 새 왕조 건설을 주장
- [ ] 최영 — 요동 정벌을 주장한 장수
- [ ] 이성계 — 신흥 무인 세력, 훗날 조선의 태조
> 정몽주와 정도전은 같은 스승 밑에서 성리학을 공부했지만 고려의 운명을 두고 의견이 갈렸다. (p.89)

### 1380년 진포에서 왜구를 물리친 인물은?
- [x] 최무선
- [ ] 최영 — 홍산에서 왜구를 물리침(1376)
- [ ] 이성계 — 황산에서 왜구를 물리침(1380)
- [ ] 정세운 — 홍건적을 물리침(1362)
> 홍건적과 왜구의 침입 지도에 나오는 인물들이다. (p.89)

## 27. 조선의 건국

### 요동을 공격하라는 명령을 받은 이성계가 군사를 돌려 개경으로 돌아와 권력을 장악한 사건은?
- [x] 위화도 회군
- [ ] 인조반정 — 서인이 광해군을 몰아내고 인조를 세운 사건(1623)
- [ ] 무신정변 — 무신들이 문신을 죽이고 권력을 잡은 사건(1170, 1학기)
- [ ] 정묘호란 — 후금이 조선을 침입한 전쟁(1627)
> 위화도 회군 이후 신진 사대부와 신흥 무인 세력이 권력을 잡았다. (p.104)

### 신진 사대부가 시행한 토지 제도로, 관리 등급에 따라 토지에서 세금을 걷을 권리를 나누어 준 것은?
- [x] 과전법
- [ ] 전시과 — 고려의 토지 제도 (1학기)
- [ ] 대동법 — 특산물 대신 쌀·옷감으로 내게 한 세금 제도
- [ ] 균역법 — 영조가 군포를 2필에서 1필로 줄인 제도
> 과전법으로 권문세족의 경제력을 약화하고, 세금을 수확량의 10분의 1로 정해 백성의 부담을 덜었다. (p.104)

### 조선의 건국에 대한 설명으로 알맞은 것은?
- [x] 1392년 이성계가 왕이 되어 나라 이름을 조선으로 바꾸고 한양으로 수도를 옮겼다.
- [ ] 918년 왕건이 송악에서 나라를 세웠다. — 고려의 건국 (1학기)
- [ ] 1392년 정몽주가 이성계를 왕으로 추대했다. — 정몽주는 고려 유지를 주장하다 제거됨
- [ ] 1446년 세종이 즉위하며 나라를 세웠다. — 1446년은 훈민정음을 반포한 해
> 정도전 등은 고려 왕조 유지를 주장한 정몽주를 제거하고 이성계(태조)를 왕으로 세웠다. (p.104)

### 한성(한양)에서 경복궁 동쪽에 두어 왕의 조상들에게 제사를 지낸 곳은?
- [x] 종묘
- [ ] 사직 — 경복궁 서쪽, 토지신과 곡식신에게 제사
- [ ] 성균관 — 유학 최고 교육 기관
- [ ] 종각 — 도성 중앙에 세운 종루
> 경복궁을 중심으로 동쪽에는 종묘, 서쪽에는 사직을 두었다. (p.104~105)

### 재상 중심의 정치와 요동 정벌을 주장하다 이방원에게 제거된 인물은?
- [x] 정도전
- [ ] 정몽주 — 고려 왕조 유지를 주장하다 조선 건국 전에 제거됨
- [ ] 최영 — 요동 정벌을 주장한 고려 말 장수
- [ ] 조광조 — 중종 때 개혁을 추진한 사림
> 정도전은 재상이 임금의 좋은 점은 따르고 나쁜 점은 바로잡아야 한다고 보았다. 이방원은 왕 중심 정치를 주장했다. (p.105)

### 태종(이방원)의 정책으로 알맞지 않은 것은?
- [x] 집현전을 설치해 학자를 길렀다.
- [ ] 사병을 없애 군사권을 장악했다. — 태종의 정책 (맞는 내용)
- [ ] 인구 조사를 실시했다. — 태종의 정책 (맞는 내용)
- [ ] 호패법을 시행했다. — 태종의 정책 (맞는 내용)
> 집현전은 세종이 설치했다. 태종은 사병 혁파, 인구 조사, 호패법으로 왕권과 국가 재정을 안정시켰다. (p.105~106)

### 세종이 유교적 소양을 갖춘 학자들을 키우기 위해 설치한 학문 연구 기관은?
- [x] 집현전
- [ ] 홍문관 — 성종이 집현전을 계승해 설치
- [ ] 규장각 — 정조가 세운 학문·정책 연구 기관
- [ ] 의금부 — 왕의 특별 사법 기관
> 집현전(세종) → 홍문관(성종이 계승) → 규장각(정조)의 흐름을 기억하자. (p.106)

### 왕이 신하들과 함께 유교 경전을 공부하고 나라의 중요한 일을 논의하던 자리는?
- [x] 경연
- [ ] 예송 — 상복 입는 기간을 둘러싼 붕당 간 논쟁
- [ ] 환국 — 숙종 때 집권 붕당이 한꺼번에 바뀐 일
- [ ] 향약 — 사림이 만든 향촌 자치 규약
> 세종은 경연을 1,898회나 열 만큼 신하들과의 대화를 중요하게 여겼다. (p.106)

### 세종이 『훈민정음』을 만든 목적으로 가장 알맞은 것은?
- [x] 한자를 모르는 백성도 쉽게 글을 익혀 쓰게 하고 유교 덕목을 가르치기 위해
- [ ] 명에 보낼 외교 문서를 쓰기 위해 — 외교와는 관계없음
- [ ] 양반만 쓰는 비밀 문자를 만들기 위해 — 오히려 모든 사람이 쉽게 익히게 하려 함
- [ ] 일본과 무역할 때 쓰기 위해 — 무역과는 관계없음
> "백성을 가르치는 바른 소리"라는 뜻이다. 1446년에 반포했다. (p.106~107)

### 충신·효자·열녀의 모범 사례를 그림과 함께 모아, 백성에게 유교 윤리를 보급하려 한 책은?
- [x] 삼강행실도
- [ ] 농사직설 — 조선의 기후와 토지에 맞는 농법서
- [ ] 경국대전 — 조선의 기본 법전
- [ ] 칠정산 — 세종 때 만든 역법서
> 삼강은 신하는 임금을, 자식은 부모를, 아내는 남편을 근본으로 섬긴다는 뜻이다. (p.107)

### 세종 때 조선의 기후와 토지에 맞는 농법을 정리해 보급한 책은?
- [x] 농사직설
- [ ] 삼강행실도 — 충신·효자·열녀 사례를 모은 책
- [ ] 칠정산 — 해·달·행성의 운행을 계산한 역법서
- [ ] 속대전 — 영조 때 바뀐 법령을 정리한 법전
> 세종은 농업 발전에 힘써 『농사직설』을 편찬하게 했다. (p.106)

### 비가 내린 양(강우량)을 측정하기 위해 만들어 각 지방에 설치한 기구는?
- [x] 측우기
- [ ] 앙부일구 — 그림자로 시간을 알려 주는 해시계
- [ ] 혼천의 — 천체의 운행을 관측하는 기구
- [ ] 간의 — 천체의 위치를 관측하는 기구
> 측우기로 내린 비의 양을 재어 왕에게 보고했다. (p.106, 109)

### 세종이 원의 수시력을 바탕으로 조선 실정에 맞게 만들어 일식·월식 예측을 정확하게 한 역법서는?
- [x] 칠정산
- [ ] 천상열차분야지도 — 태조 때 별자리를 새긴 천문도
- [ ] 농사직설 — 조선에 맞는 농법서
- [ ] 삼강행실도 — 유교 윤리를 보급한 책
> '칠정산'은 해, 달, 화성, 수성, 목성, 금성, 토성 7개 천체의 운행을 계산하는 방법이라는 뜻이다. (p.109)

### 형벌보다 덕으로 백성을 다스리고, 왕이 먼저 덕을 갖춰 모범을 보일 것을 강조하는 정치는?
- [x] 왕도 정치

## 31. 임진왜란

### 분열된 일본을 통일하고 국내 불만을 잠재우기 위해 조선을 침략한 인물은?
- [x] 도요토미 히데요시
- [ ] 이삼평 — 일본에 끌려가 도자기 산업의 시조가 된 조선 도공
- [ ] 아담 샬 — 소현세자가 청에서 만난 서양 선교사
- [ ] 사야가 — 조선에 귀화한 일본군 장수(김충선)
> 일본은 명을 치러 가는 길을 빌려달라는 구실로 조선을 침략했다(임진왜란, 1592). (p.122)

### 전쟁 1년 전 일본에 다녀와 "반드시 전쟁이 일어날 것"이라고 보고한 사람은?
- [x] 황윤길
- [ ] 김성일 — "두려워할 위인이 못 된다"며 전쟁 준비를 반대
- [ ] 이순신 — 바다에서 활약한 수군 장수
- [ ] 권율 — 행주산성에서 승리한 장수
> 조선은 김성일의 의견을 따라 전쟁 준비를 강화하지 않았다. (p.122)

### 임진왜란 초기 일본군이 조선군을 밀어붙인 무기로, 포르투갈과 교류하며 얻은 것은?
- [x] 조총
- [ ] 화포 — 조선 수군이 배에 실은 대포
- [ ] 거북선 — 철갑을 덮은 조선 수군의 배
- [ ] 판옥선 — 조선 수군의 주력 배
> 조선은 조총을 앞세운 일본군에게 두 달 만에 한양과 평양을 빼앗겼다. (p.122)

### 한양과 평양이 함락되자 선조가 피난한 곳은?
- [x] 의주
- [ ] 강화도 — 고려가 몽골 침입 때 수도를 옮긴 곳 (1학기)
- [ ] 남한산성 — 병자호란 때 인조가 피난한 곳
- [ ] 진주 — 김시민이 승리한 진주성이 있는 곳
> 선조는 의주로 피난하고 명에 지원군을 요청했다. (p.122)

### 관군을 대신해 지역을 지킨 의병에 대한 설명으로 알맞은 것은?
- [x] 전직 관리, 유학자, 농민, 승려 등이 조직해 지형을 이용해 싸웠다.
- [ ] 명에서 보낸 지원군이었다. — 명군은 의병과 별도로 참전
- [ ] 나라에서 월급을 주는 직업 군인이었다. — 직업 군인은 훈련도감
- [ ] 일본군에 항복한 조선군이었다. — 항복한 일본인은 '항왜'
> 대표 의병장: 곽재우, 조헌, 김천일, 서산 대사, 사명 대사 등. (p.123)

### 임진왜란 때 진주성에서 관군을 이끌고 승리를 거둔 인물은?
- [x] 김시민
- [ ] 권율 — 행주산성에서 승리
- [ ] 이순신 — 수군을 이끌고 바다에서 활약
- [ ] 곽재우 — 의령에서 일어난 의병장
> 김시민의 진주 대첩, 이순신의 수군 활약으로 곡창 지대인 전라도를 지킬 수 있었다. (p.123)

### 행주산성에서 승리를 거두어 한양을 되찾는 발판을 마련한 인물은?
- [x] 권율
- [ ] 김시민 — 진주성에서 승리
- [ ] 이순신 — 한산도·명량·노량 등 바다에서 승리
- [ ] 김충선 — 조선에 귀화한 일본군 장수
> 명의 지원군과 함께 평양성을 되찾은 뒤, 권율이 행주 대첩(1593)에서 승리했다. (p.123)

### 3년간의 휴전 회담이 결렬된 뒤 일본이 조선을 다시 침략한 전쟁은?
- [x] 정유재란
- [ ] 정묘호란 — 후금이 조선을 침입한 전쟁(1627)
- [ ] 병자호란 — 청이 조선을 침입한 전쟁(1636)
- [ ] 인조반정 — 서인이 광해군을 몰아낸 사건
> 정유재란(1597)은 도요토미 히데요시가 죽고 일본군이 철수하면서 끝나, 7년 전쟁이 막을 내렸다. (p.123)

### 임진왜란이 동아시아에 끼친 영향으로 알맞지 않은 것은?
- [x] 고려가 멸망하고 조선이 세워졌다.
- [ ] 일본에서는 에도 막부가 세워졌다. — 왜란의 영향 (맞는 내용)
- [ ] 명의 국력이 약해진 틈에 여진족이 후금을 세웠다. — 왜란의 영향 (맞는 내용)
- [ ] 조선의 인구와 농경지가 크게 줄었다. — 왜란의 영향 (맞는 내용)
> 조선 건국은 1392년으로 임진왜란(1592)보다 200년 앞선다. (p.124)

### 일본에 끌려가 아리타 지역에서 일본 도자기 산업의 시조가 된 조선인 도공은?
- [x] 이삼평
- [ ] 김충선 — 조선에 귀화한 일본군 장수
- [ ] 홍호연 — 12세에 일본에 끌려가 서예로 유명해진 인물
- [ ] 김육 — 대동법 확대를 주장한 인물
> 포로로 끌려간 조선인 유학자와 도공들의 영향으로 일본의 성리학과 도자기 산업이 발달했다. (p.124)

### 임진왜란 때 조선에 귀화해 조총 기술을 전하고 '김충선'이라는 이름을 받은 일본군 장수는?
- [x] 사야가
- [ ] 이삼평 — 일본에 끌려간 조선 도공
- [ ] 홍호연 — 일본에 끌려간 조선인 서예가
- [ ] 도요토미 히데요시 — 조선을 침략한 일본의 지배자
> 사야가는 명분 없는 전쟁을 비판하며 부하 3,000명과 함께 귀화했다. 이처럼 조선에 항복해 정착한 일본인을 '항왜'라고 했다. (p.125)

### 명(중국)이 조선을 도와 일본에 맞섰다는 뜻으로 임진왜란을 부르는 이름은?
- [x] 항왜원조 전쟁
- [ ] 분로쿠·게이초의 역 — 일본에서 부르는 이름
- [ ] 임진왜란 — 조선에서 부르는 이름
- [ ] 정유재란 — 일본이 다시 침략한 전쟁(1597)
> 하나의 사건을 나라마다 다르게 부르며 다르게 평가한다. (p.124)

## 32. 병자호란

- [ ] 인조 — 친명배금 정책을 펼침
- [ ] 선조 — 임진왜란 때의 왕
- [ ] 효종 — 북벌을 추진한 왕
> 광해군은 전쟁 피해 복구에 힘쓰면서, 명이 쇠퇴하고 후금이 성장하는 상황에서 중립 외교를 펼쳤다. (p.126)

### 광해군의 명으로 명을 도우러 갔다가, 명이 패하자 곧바로 후금에 항복한 지휘관은?
- [x] 강홍립
- [ ] 김시민 — 임진왜란 때 진주성에서 승리
- [ ] 권율 — 임진왜란 때 행주산성에서 승리
- [ ] 이순신 — 임진왜란 때 수군을 이끈 장수
> 광해군은 "상황을 잘 판단해 행동하라"고 지시해 후금과의 전쟁을 피했지만, 서인의 강한 비판을 받았다. (p.126)

### 서인이 광해군을 몰아내고 인조를 왕으로 세운 사건(1623)은?
- [x] 인조반정
- [ ] 위화도 회군 — 이성계가 요동 공격을 멈추고 돌아온 사건
- [ ] 무신정변 — 고려 무신들이 권력을 잡은 사건 (1학기)
- [ ] 예송 — 상복 입는 기간을 둘러싼 논쟁
> 서인은 광해군이 명을 배신하고 인륜을 저버렸다고 비판하며 반정을 일으켰다. (p.126)

### 인조반정 이후 서인 정권이 추진한 외교 정책은?
- [x] 친명배금
- [ ] 중립 외교 — 광해군의 외교 정책
- [ ] 사대교린 — 조선 전기의 외교 정책
- [ ] 북벌론 — 병자호란 이후 청을 치자는 주장
> 친명배금은 명과 친하게 지내고 후금을 배척하는 정책이다. (p.126)

### 정묘호란(1627) 때 후금 군대가 돌아간 조건은?
- [x] 조선이 후금과 형제 관계를 맺기로 약속했다.
- [ ] 조선이 청과 군신 관계를 맺었다. — 병자호란의 결과
- [ ] 조선의 4도를 후금에 넘겨주었다. — 임진왜란 때 일본이 내건 무리한 조건
- [ ] 인조가 삼전도에서 항복했다. — 병자호란의 결과
> 정묘호란은 형제 관계, 병자호란은 군신(임금과 신하) 관계로 끝났다. (p.126~127)

### 병자호란(1636) 때 인조가 피난해 청군에 맞서다 항복한 곳은?
- [x] 남한산성
- [ ] 강화도 — 고려가 몽골 침입 때 수도를 옮긴 곳 (1학기)
- [ ] 의주 — 임진왜란 때 선조가 피난한 곳
- [ ] 행주산성 — 임진왜란 때 권율이 승리한 곳
> 청군에 포위된 남한산성에서 많은 사람이 혹독한 추위와 굶주림으로 고통받았다. (p.127)

### 인조가 청 태종에게 굴욕적으로 항복한 사실이 적혀 있는 비석은?
- [x] 삼전도비
- [ ] 탕평비 — 영조가 탕평 정치를 알리려 세운 비석
- [ ] 대보단 — 명 황제에게 제사 지낸 제단
- [ ] 종묘 — 왕의 조상에게 제사 지내는 곳
> 병자호란 이후 조선은 명과의 관계를 끊고 청과 사대 관계를 맺었다. (p.127)

### 병자호란 이후 '청에 당한 굴욕을 갚고 명의 원수를 갚자'며 청을 공격하자는 주장은?
- [x] 북벌론

- [ ] 중립 외교 — 광해군의 외교 정책
- [ ] 사대교린 — 조선 전기의 외교 정책
> 남한산성에서는 끝까지 싸우자는 주전론과 일단 나라를 지키자는 주화론이 대립했다. (p.127)

### 세력이 강해진 후금이 바꾼 나라 이름은?
- [x] 청
- [ ] 명 — 청에게 밀려 17세기 중반 멸망한 나라
- [ ] 금 — 고려 때 여진이 세운 나라 (1학기)

> 후금은 국호를 청으로 바꾸고 스스로 황제라 칭하며 조선에 군신 관계를 요구했다. (p.127)

### 병자호란 때 박씨 성의 여인이 청의 군대를 물리치는 내용으로, 조선 후기에 유행한 소설은?

## 33. 양 난 이후의 변화

- [ ] 승정원 — 왕의 비서 기관

### 대동법에 대한 설명으로 알맞은 것은?
- [x] 소유한 토지 넓이를 기준으로 쌀이나 옷감, 동전으로 세금을 내게 했다.

### 많은 반대를 무릅쓰고 평생 대동법 확대와 동전 유통을 주장한 인물은?

- [ ] 채제공 — 정조 때 금난전권의 폐해를 아뢴 좌의정

### 지주들이 대동법 시행에 반대한 까닭으로 알맞은 것은?
- [x] 땅을 많이 가질수록 세금을 많이 내야 했기 때문이다.
- [ ] 특산물을 더 많이 바쳐야 했기 때문이다. — 대동법은 특산물 대신 쌀 등으로 냄
- [ ] 군대에 직접 가야 했기 때문이다. — 대동법은 군역과 관계없음
- [ ] 동전을 쓸 수 없게 되었기 때문이다. — 오히려 동전 사용이 늘어남
> 대동법은 토지 넓이를 기준으로 걷어 땅이 적은 농민의 부담은 줄고 지주의 부담은 늘었다. 그래서 전국 확대에 약 100년이 걸렸다. (p.135)

### 대동법이 시행되기 전, 백성이 지역 특산물을 구해다 바치던 세금은?
- [x] 공납
- [ ] 군포 — 군역 대신 내던 옷감
- [ ] 환곡 — 곡식을 빌려주었다가 돌려받는 제도
- [ ] 대동법 — 공납 대신 쌀·옷감으로 내게 한 제도
> 공납은 특산물을 다른 마을이나 상인에게 비싸게 사서 바쳐야 하는 폐단이 컸다. (p.135)

### 청에 인질로 있으며 선교사 아담 샬을 만나 천주교와 서양 문물을 접한 왕자는?
- [x] 소현세자
- [ ] 봉림대군 — 소현세자의 동생, 훗날 효종
- [ ] 연잉군 — 훗날의 영조
- [ ] 수양대군 — 훗날의 세조
> 소현세자는 서양 문물을 조선에 보급하려 했으나, 귀국 후 석 달도 안 되어 세상을 떠났다. (p.137)

### 소현세자가 죽은 뒤 왕위에 올라, 청에 대한 복수를 외치며 북벌을 추진한 왕은?
- [x] 효종
- [ ] 인조 — 병자호란 때 청에 항복한 왕
- [ ] 현종 — 예송이 일어난 때의 왕
- [ ] 숙종 — 환국을 일으킨 왕
> 봉림대군(효종)은 서인을 등용하고 군사력을 키웠지만, 효종이 죽은 후 북벌은 사실상 중단됐다. (p.137)

### 북벌이 실현되지 못한 뒤, 조선만이 중화 문명의 유일한 계승자라고 여긴 생각은?
- [x] 조선 중화론
- [ ] 중립 외교 — 광해군의 외교 정책
- [ ] 주화론 — 병자호란 때 화친을 주장한 의견
- [ ] 친명배금 — 인조 정권의 외교 정책
> 조선은 대보단을 세워 임진왜란 때 원군을 보낸 명 황제에게 제사를 지내며 이런 생각을 드러냈다. (p.137)

## 34. 붕당 간 대립

### 광해군 때 권력을 독점했던 붕당으로, 왜란 때 의병장으로 활약한 사람이 많았던 붕당은?
- [x] 북인
- [ ] 남인 — 인조반정 후 서인과 함께 정치에 참여
- [ ] 노론 — 서인에서 갈라진 강경파
- [ ] 소론 — 서인에서 갈라진 온건파
> 인조반정 이후에는 서인이 우세한 가운데 남인이 정치에 참여했다. (p.138)

### 사림이 동인과 서인으로 갈라진 뒤, 동인이 다시 나뉜 두 붕당은?
- [x] 북인과 남인
- [ ] 노론과 소론 — 서인이 다시 나뉜 붕당
- [ ] 훈구와 사림 — 붕당 이전에 대립한 세력
- [ ] 동인과 서인 — 사림이 처음 나뉜 붕당
> 동인은 정치적으로 곤란해진 서인을 처리하는 문제를 두고 북인과 남인으로 나뉘었다. (p.138)

### 현종 때(1670~1671) 소빙하기의 영향으로 일어난 조선 시대 최악의 재난은?
- [x] 경신대기근
- [ ] 병자호란 — 청의 침입(1636)
- [ ] 정묘호란 — 후금의 침입(1627)
- [ ] 임진왜란 — 일본의 침입(1592)
> 실록에는 '참혹한 죽음이 임진년(임진왜란) 때보다 더하다'라는 기록이 있다. (p.138)

### 경신대기근 때 조선 정부가 재난을 극복하려고 한 일로 알맞지 않은 것은?
- [x] 세금을 더 걷어 군대를 늘렸다.
- [ ] 서인과 남인 출신 재상이 협력해 진휼 정책을 펼쳤다. — 맞는 내용
- [ ] 왕실 비용과 관리 급료, 군사비를 줄였다. — 맞는 내용
- [ ] 농가가 환곡으로 진 빚을 없애 주었다. — 맞는 내용
> 이때는 붕당의 이해관계를 따지지 않고 백성을 구하기 위해 협력했고, 토지세 등 세금도 줄였다. (p.138)

### 효종과 효종비의 장례 때 자의대비가 상복을 얼마 동안 입어야 하는지를 두고 벌어진 논쟁은?
- [x] 예송
- [ ] 환국 — 숙종 때 집권 붕당이 한꺼번에 바뀐 일
- [ ] 사화 — 훈구와의 대립으로 사림이 피해를 입은 사건
- [ ] 탕평 — 영조·정조가 붕당 대립을 줄이려 한 정치
> 예송은 예법 토의로 시작했으나 왕실 정통성에 관한 정치 논쟁으로 번졌다. 1차 예송은 서인, 2차 예송은 남인의 주장이 채택되었다. (p.139)

### 숙종 때 여러 번 일어난, 권력을 잡은 붕당이 하루아침에 바뀌는 일을 무엇이라고 할까?
- [x] 환국
- [ ] 예송 — 상복 입는 기간을 둘러싼 논쟁
- [ ] 반정 — 신하들이 왕을 몰아내고 새 왕을 세운 일
- [ ] 사화 — 사림이 피해를 입은 사건
> 숙종은 집권 붕당을 바꿀 때마다 다른 붕당을 쫓아내며 왕권을 강화하려 했지만, 붕당 정치는 더욱 변질되었다. (p.139)

### 남인을 처리하는 문제를 두고 서인이 나뉜 두 세력은?
- [x] 노론과 소론
- [ ] 동인과 서인 — 사림이 처음 나뉜 붕당
- [ ] 남인과 북인 — 동인이 나뉜 붕당
- [ ] 훈구와 사림 — 붕당 이전에 대립한 세력
> 강경파는 노론, 온건파는 소론이다. 숙종 말기 노론은 연잉군(영조), 소론은 세자(경종)를 지지했다. (p.139)

## 35. 탕평 정치

### 붕당 간 대립을 줄이고 왕권을 강화하기 위해 영조와 정조가 펼친 정치는?
- [x] 탕평 정치
- [ ] 붕당 정치 — 여러 붕당이 견제·균형하며 이끈 정치
- [ ] 왕도 정치 — 덕으로 백성을 다스리는 유교 정치
- [ ] 중립 외교 — 광해군의 외교 정책
> 영조는 상대 붕당을 인정하는 온건한 인물을 등용하고, 탕평비를 세워 탕평 정치를 알렸다. (p.140)

### 영조의 정책으로 알맞지 않은 것은?
- [x] 규장각을 설치해 젊은 관료를 길렀다.
- [ ] 붕당의 근거지인 서원을 대폭 정리했다. — 영조의 정책 (맞는 내용)
- [ ] 『속대전』을 편찬했다. — 영조의 정책 (맞는 내용)
- [ ] 청계천을 정비했다. — 영조의 정책 (맞는 내용)
> 규장각은 정조가 설치했다. 영조는 이 밖에 균역법, 신문고, 혹독한 형벌 금지 등을 추진했다. (p.140~141)

### 영조가 군역 대신 내던 군포를 2필에서 1필로 줄인 제도는?
- [x] 균역법
- [ ] 대동법 — 공납 대신 쌀·옷감으로 내게 한 제도
- [ ] 과전법 — 조선 건국 직전의 토지 제도
- [ ] 호패법 — 태종 때 신분증을 차게 한 제도
> 부족한 세금은 토지 소유자에게 더 거두는 등 여러 방법으로 보충했다. (p.140)

### 정조가 세운 왕실 도서관이자 학문·정책 연구 기관으로, 서얼 출신도 등용한 곳은?
- [x] 규장각
- [ ] 집현전 — 세종 때의 학문 연구 기관
- [ ] 홍문관 — 성종이 집현전을 계승해 세운 기관
- [ ] 성균관 — 유학 최고 교육 기관
> 규장각은 세종 때의 집현전처럼 왕과 관리가 함께 학문을 연구하고 정책을 개발하는 곳이었다. (p.141)

### 정조가 왕을 지키고 군사적 기반을 강화하기 위해 조직한 특별 부대는?
- [x] 장용영
- [ ] 훈련도감 — 임진왜란 중 설치한 직업 군인 부대
- [ ] 속오군 — 양 난 이후의 지방군
- [ ] 별무반 — 고려 윤관이 만든 부대 (1학기)
> 정조는 장용영으로 군사적 기반을 다졌다. (p.141)

### 정조가 자유로운 상업 활동을 보호하기 위해 일부 없앤, 시전 상인이 난전을 단속하던 특권은?
- [x] 금난전권
- [ ] 공납 — 지역 특산물을 바치던 세금
- [ ] 음서 — 고위 관리 자손이 시험 없이 관직에 오르던 제도 (1학기)
- [ ] 군포 — 군역 대신 내던 옷감
> 금난전권이 폐지되자 백성들은 더 싼 값에 생필품을 구할 수 있게 되었다. (p.141)

### 정조가 자신의 정치적 이상을 실현할 도시로 건설한 곳은?
- [x] 수원 화성
- [ ] 남한산성 — 병자호란 때 인조가 피난한 곳
- [ ] 행주산성 — 임진왜란 때 권율이 승리한 곳
- [ ] 한성 — 조선의 수도(한양)
> 정조는 규장각과 장용영으로 왕권을 강화하고 수원 화성을 건설했다. (p.141)
